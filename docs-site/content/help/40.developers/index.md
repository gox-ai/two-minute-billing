Everything the dashboard does, your code can do over HTTP.

- [Quickstart](/help/developers/getting-started/quickstart) — a test key, then a paid subscription, in TypeScript or curl.
- [Test and live mode](/help/developers/getting-started/test-and-live) — the two modes of every business, and test cards for every failure.
- [Concepts](/help/developers/concepts/account-hierarchy) — the objects and how money moves between them.
- [Recipes](/help/developers/recipes) — trials, usage-based billing, one-time purchases, failed payments, India GST and mandates.
- [API essentials](/help/developers/api-essentials/authentication) — authentication, idempotency, errors and pagination.
- [Webhooks](/help/developers/webhooks) — signature verification, retries and the event catalogue.
- [API reference](/help/developers/api-reference) — every endpoint.
