Bill Indian customers with GST worked out per invoice. tmbilling compares the state you supply
from with the customer's state (the place of supply). The same state gets CGST and SGST. A
different state gets IGST. Your GSTIN, the customer's GSTIN and the HSN or SAC code print on the
invoice.

## Before you begin

You need a test API key and the client from the [Quickstart](/help/developers/getting-started/quickstart).
Rates and states below are examples: use the rates that apply to what you sell. Responses are
shortened to the fields that matter here.

```ts [setup.ts]
import { Tmbilling } from "@two-minute-billing/sdk";

const tmb = new Tmbilling({
  apiKey: process.env.TMBILLING_API_KEY!,
  baseUrl: process.env.TMBILLING_URL,
});

// The client does not type every tax field yet. This helper sends any request with your key.
async function api<T>(method: string, path: string, body?: unknown): Promise<T> {
  const res = await fetch(`${process.env.TMBILLING_URL}${path}`, {
    method,
    headers: {
      Authorization: `Bearer ${process.env.TMBILLING_API_KEY}`,
      "Idempotency-Key": crypto.randomUUID(),
      ...(body === undefined ? {} : { "Content-Type": "application/json" }),
    },
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  if (!res.ok) throw new Error(`${res.status} ${await res.text()}`);
  return (await res.json()) as T;
}
```

## Put your GSTIN on the business

The invoice prints the seller's name, address and GSTIN from the business, and freezes them when
the invoice is issued. Set the business address in India and its GSTIN. The label "GSTIN" comes
from the address country.

::code-group
```ts [TypeScript]
await tmb.businesses.update(biz.id, {
  address: { line1: "10 Residency Road", city: "Bengaluru", state_code: "KA", postal_code: "560025", country: "IN" },
  tax_registration_number: "29AAAAA0000A1Z5",
});
```

```bash [curl]
curl -X PATCH $TMBILLING_URL/v1/businesses/$BIZ \
  -H "Authorization: Bearer $TMBILLING_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "address": { "line1": "10 Residency Road", "city": "Bengaluru", "state_code": "KA", "postal_code": "560025", "country": "IN" },
    "tax_registration_number": "29AAAAA0000A1Z5"
  }'
```
::

::note{title="Several businesses under one GSTIN"}
If one registered company bills through several businesses, set the organization's legal name,
address and GSTIN, and set `invoice_issuer` to `organization` on each business. The invoice then
names the company as the seller.
::

## Turn on GST for India

A tax region makes one country taxable. Set `regime` to `gst` and `home_state_code` to the state
you supply from, as an ISO 3166-2 code without the country prefix (`KA` is Karnataka). The home
state decides intra-state or inter-state for every sale.

::code-group
```ts [TypeScript]
const region = await tmb.taxRegions.create(biz.id, {
  country: "IN",
  regime: "gst",
  home_state_code: "KA",
});
```

```bash [curl]
curl -X POST $TMBILLING_URL/v1/businesses/$BIZ/tax_regions \
  -H "Authorization: Bearer $TMBILLING_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "country": "IN",
    "regime": "gst",
    "home_state_code": "KA"
  }'

export TXG=txg_…
```
::

```json [Response]
{
  "object": "tax_region",
  "id": "txg_XXXXXXXXXXXXXXXXXXXXXX01",
  "country": "IN",
  "regime": "gst",
  "price_type": "exclusive",
  "home_state_code": "KA",
  "enabled": true,
  "components": []
}
```

## Set the GST rates

The region's tax is a list of components. `applies_to` says when each one applies: `intra` for a
sale inside your home state, `inter` for a sale to another state. Rates are basis points, so
`900` is 9%. Set IGST to the sum of CGST and SGST.

::code-group
```ts [TypeScript]
await tmb.taxRegions.setComponents(biz.id, region.id, {
  components: [
    { name: "CGST", rate_bps: 900, applies_to: "intra" },
    { name: "SGST/UTGST", rate_bps: 900, applies_to: "intra" },
    { name: "IGST", rate_bps: 1800, applies_to: "inter" },
  ],
});
```

```bash [curl]
curl -X PUT $TMBILLING_URL/v1/businesses/$BIZ/tax_regions/$TXG/components \
  -H "Authorization: Bearer $TMBILLING_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "components": [
      { "name": "CGST", "rate_bps": 900, "applies_to": "intra" },
      { "name": "SGST/UTGST", "rate_bps": 900, "applies_to": "intra" },
      { "name": "IGST", "rate_bps": 1800, "applies_to": "inter" }
    ]
  }'
```
::

```json [Response]
{
  "object": "list",
  "data": [
    {
      "object": "tax_rate_component",
      "id": "txc_XXXXXXXXXXXXXXXXXXXXXX01",
      "name": "CGST",
      "rate_bps": 900,
      "applies_to": "intra",
      "state_code": null
    },
    {
      "object": "tax_rate_component",
      "id": "txc_XXXXXXXXXXXXXXXXXXXXXX02",
      "name": "SGST/UTGST",
      "rate_bps": 900,
      "applies_to": "intra",
      "state_code": null
    },
    {
      "object": "tax_rate_component",
      "id": "txc_XXXXXXXXXXXXXXXXXXXXXX03",
      "name": "IGST",
      "rate_bps": 1800,
      "applies_to": "inter",
      "state_code": null
    }
  ]
}
```

This call replaces the whole list. To give one state a different rate, send the same call with
`state_code`: that list then wins for sales into that state.

## Add the HSN or SAC code

`tax_code` holds the HSN or SAC code that prints on each invoice line. tmbilling reads it from the
price first, then the product, then the business's `default_tax_code`. Set it once on the
product.

::code-group
```ts [TypeScript]
const product = await api<{ id: string }>("POST", `/v1/businesses/${biz.id}/products`, {
  name: "Pro",
  tax_code: "998314",
});

const price = await tmb.prices.create(biz.id, {
  product: product.id,
  name: "Pro monthly",
  model: "flat",
  currency: "INR",
  amount_minor: 249900,
  interval: "month",
  tax_behavior: "exclusive",
});
```

```bash [curl]
curl -X POST $TMBILLING_URL/v1/businesses/$BIZ/products \
  -H "Authorization: Bearer $TMBILLING_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Pro", "tax_code": "998314" }'

curl -X POST $TMBILLING_URL/v1/businesses/$BIZ/prices \
  -H "Authorization: Bearer $TMBILLING_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "product": "pro",
    "name": "Pro monthly",
    "model": "flat",
    "currency": "INR",
    "amount_minor": 249900,
    "interval": "month",
    "tax_behavior": "exclusive"
  }'
```
::

`tax_behavior: "exclusive"` adds GST on top of ₹2,499.00. With `inclusive`, ₹2,499.00 is the
total and tmbilling takes the tax out of it, using the one combined rate.

## Check it worked

- `seller_state_code` and `place_of_supply_code` on the invoice are the two states tmbilling
  compared. Equal means CGST and SGST. Different means IGST.
- `tax_origin.registration_number` is your GSTIN and `customer_tax_id` is the buyer's, both
  frozen at issue. Changing the business later does not rewrite issued invoices.
- `GET /v1/businesses/{biz}/invoices/{inv}/pdf` returns the tax invoice, with an HSN/SAC column
  and one row per tax component.

## Common errors

| What you see | Why | What to do |
|---|---|---|
| The estimate has no `tax_lines` | The customer has no `country`, or no enabled tax region matches it. | Set the customer's billing address with `country: "IN"`. |
| IGST on a sale inside your state | The customer's `state_code` differs from `home_state_code`, or is missing. | Set the customer's billing `state_code`. A customer with no state is taxed as inter-state. |
| `state_code takes the code, not the name. Use "KA" for Karnataka` | You sent the state name in `state_code`. | Send the code. Put the name in `state` if you want it printed. |
| `A flat region can have only 'both' components…` | The region's `regime` is not `gst`, so `intra` and `inter` cannot apply. | Create the region with `regime: "gst"`. |
| `component names must be unique within a state scope` | Two components share a name. | Give each component its own name. |
