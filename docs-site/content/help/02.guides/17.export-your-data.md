Take a copy of your billing data whenever you need it: for your accountant, your spreadsheets or
your data warehouse, or to move records into another business. An export is one zip of CSV files,
all taken at the same moment.

Open **Settings › Import and export data** and select **Export data**. On a list such as
Customers or Invoices, **Export › Export all in the background** opens the same screen for that
list's records. Exporting needs an owner or an admin.

## Choose what to export

Each record type is one file. Select the ones you want:

| Record type | One row is | Filters |
|---|---|---|
| Plans and prices, Add-ons | a price | include archived |
| Coupons | a coupon | include archived |
| Customers | a customer, with the reference to their saved card | created or last changed, in a date range |
| Subscriptions | an item of a subscription | status; created or last changed, in a date range |
| Invoices | a line of an invoice | status (paid, open, void); issued in a date range |
| Credit notes | a credit note | issued in a date range |
| Payments and refunds | a payment or a refund | status (succeeded, failed); date range |
| Usage | a usage record | a date range (required, because usage can be very large) |

Each record type shows how many records it has with your filters. Select **Preview** to see the
first rows exactly as the file will have them, and what each column holds.

**Include the records they refer to** is on by default. An export of last month's invoices then
also writes their customers, subscriptions and prices, so the files import on their own. The
screen tells you how many records were added this way.

## Export and download

Select **Export**. The export runs in the background: you can close the page, and we send you an
email when it is ready. One export runs at a time in a business.

When it is ready, select **Download all** for the zip, or **Download** for one file. The zip also
has a `README.txt` that says when the export was taken and what each file holds. We keep the
files for 7 days, then delete them. To delete them sooner, select **Delete files**.

**Past exports** lists every export with who started it and when. **Export again** fills in the
same record types and filters, so you can take a new copy in one step.

## What is in the files

- **The columns that the import reads, first.** You can upload the files on **Import files** in
  another business without changes. Columns that the import does not read, such as a
  subscription's monthly recurring revenue, come after them.
- **Amounts** are in the currency's main unit (`49.00`). **Dates and times** are in UTC.
- **Invoices** have one row for each line, with the tax and the discount on the first line.
- **Card numbers are never in a file.** A customer's card is a reference to the card saved at your
  payment gateway.
- **Text that a spreadsheet could run as a formula**, such as a phone number that starts with
  `+`, gets a `'` before it. The import removes it.
- **Left out:** draft invoices, usage prices and pricing models that the import cannot read. The
  export lists them, with the reason.

Each download is in the audit log, with who downloaded it.

To export with the API, see [Export to CSV files](/help/developers/recipes/export-to-csv-files).
