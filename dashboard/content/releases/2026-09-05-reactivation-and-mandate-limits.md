---
title: Reactivation rules, and a mandate warning before you commit
date: 2026-09-05
type: Feature
tags: Subscriptions
summary: Choose whether reactivation requires a payment, and see at create time whether the mandate can carry the amount.
---

**Reactivation is configurable.** Whether bringing a cancelled subscription back requires a successful
payment first is now a setting, so the rule can match how you actually sell.

**A mandate limit is flagged at create time.** When a subscription's amount would exceed what the
customer's mandate is authorised to carry, the create screen says so — while it is still a decision,
rather than at the first renewal.

The reactivation preview also shows the same totals the invoice will carry, so the number you approve
is the number that gets billed.
